# Olá, eu sou David Aires 👋

Desenvolvo produtos digitais que conectam **inteligência artificial, automação, marketing e experiência do usuário**. Meus projetos vão de SaaS com integrações complexas a sites comerciais e ferramentas para operação de negócios.

## Projetos em destaque

### Atlas Ads AI

Plataforma SaaS multiempresa para analisar e operar contas Meta Ads por linguagem natural. Integra IA, Telegram e WhatsApp, com confirmação antes de alterações e controles de segurança por workspace.

**Tecnologias:** Next.js, React, TypeScript, Supabase/PostgreSQL, OpenAI API, Meta Marketing API, Docker e Caddy.

[Ver estudo de caso](https://github.com/Davidairess/atlas-ads-ai-case-study)

### Atlas Growth CRM

CRM multitenant para gestão de leads, funil comercial e conversas, integrado à Evolution API, Meta Lead Ads, WhatsApp Cloud API e Conversions API.

**Tecnologias:** Next.js, TypeScript, Supabase, PostgreSQL, Docker, Meta APIs e webhooks.

[Ver estudo de caso](https://github.com/Davidairess/atlas-growth-crm-case-study)

### Aires Sound

Experiência web cinematográfica para artista musical, com identidade visual, páginas editoriais, conteúdo responsivo e publicação em VPS.

**Tecnologias:** React, TypeScript, Vite, CSS responsivo, Docker, Nginx e Caddy.

[Ver estudo de caso](https://github.com/Davidairess/aires-sound-case-study)
